With forwarding enabled, the latest fresh reading is sent once per second. The agent assesses every 10 forwarded readings by default, using Claude if it has an API key (readings are then sent to Anthropic) or its built-in rules if not. If the agent is started with --chain, it also records warning and critical results on Solana devnet, where they are public. Stop forwarding to stop sending new data; an in-progress request may still finish. This page cannot retrieve the Arduino's source code.
How to start the agent
  1. Agent: in a terminal, go to the folder with Agent.py and run python3 Agent.py (Windows: py Agent.py). Leave that window open. No packages or API key needed.
  2. Page: in a second terminal, go to the folder with this file and run python3 -m http.server 8000 (Windows: py -m http.server 8000), then open http://localhost:8000/dashboard.html in Chrome or Edge.
  3. Close the Arduino IDE's Serial Monitor, click Connect Arduino, then Start forwarding to agent.
  4. Optional: for Claude's explanations, pip install anthropic and set ANTHROPIC_API_KEY before starting the agent. To record warnings on Solana devnet, pip install solana solders and start it with python3 Agent.py --chain.
